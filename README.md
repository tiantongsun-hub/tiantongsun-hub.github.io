# Tiantong Sun — personal research website

Static GitHub Pages website. No build or dependencies.

Publish the contents of this directory to the public repository
`tiantongsun-hub/tiantongsun-hub.github.io`.
In Settings → Pages choose Deploy from a branch → main → / (root).
Expected URL after successful deployment: https://tiantongsun-hub.github.io/

Only public arXiv papers are linked. The unpublished shortcut-learning manuscript,
transcripts, local configuration and credentials are not included.

Preview: `python -m http.server 8512 --bind 127.0.0.1`
